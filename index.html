初期設定（最初の1回だけ）

このアプリを動かすには、無料のFirebaseにつなぐ必要があります。下の手順で firebaseConfig を index.html 内の該当箇所に貼り替えてください。

  1. Firebaseコンソールでプロジェクト作成
  2. 「Authentication」→ ログイン方法 → 匿名を有効化
  3. 「Realtime Database」を作成（テストモードでOK）
  4. プロジェクト設定 → マイアプリ → Webアプリ追加 → 表示される firebaseConfig をコピー
  5. index.html の const firebaseConfig = {...} に貼り替えて再デプロイ

詳しい手順は README.md を見てください。
